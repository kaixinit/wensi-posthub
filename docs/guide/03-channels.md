# 渠道绑定与收件验证

## 个人微信：微信渠道配置

1. 在“下游渠道”或应用内的“＋ 添加渠道”选择个人微信，打开“微信渠道配置”。
2. 填写渠道名称，例如“文思量化微信1”，选择连接方式，点击“保存并进入扫码”，页面直接显示二维码，不再额外确认保存草稿。
3. 使用**接收通知的本人微信**扫码，并在手机上确认。页面自动检查状态；二维码过期可重新获取。若手机要求授权验证码，在“手机授权验证码”中输入并提交。
4. 授权后，在微信的 ClawBot 会话中发送一句“文思邮差测试”。平台自动获取该账号的收件会话，也可点击“刷新微信会话”。其他微信会话不会自动替换收件人。
5. 点击“发送收件验证码”。这条消息同时用于测试发送，消息内包含渠道名称和 6 位收件验证码。
6. 查看微信中收到的消息，将验证码填入网页并完成验证。成功后显示“已完成验证”，即可在应用中勾选使用。

**手机授权验证码与收件验证码不同。** 前者用于微信扫码登录；后者由文思邮差发送，用于确认具体收件目标，10 分钟有效。同一渠道 10 分钟内最多发送 3 次收件验证消息。

更换微信账号时点击“重新扫码绑定”。新授权成功后需重新验证，旧收件验证码不能确认新账号。仅取消重新扫码不会改变原绑定。当前版本支持本人扫码授权，不支持输入普通微信号直接发送，也不支持借用其他账号完成授权。

若投递显示“等待微信会话”，请在已绑定收件微信中给机器人发一句话。平台后台获取新会话后自动续发仍未过期的消息，不必重新绑定；收件验证仍按原渠道保留。详细规则见“分发、时间与回执”。

## QQ：QQ 渠道配置

1. 填写 QQ 官方机器人 AppID、AppSecret，选择个人或群。点击“校验并保存机器人”。默认主动连接适合局域网，无需公网回调。
2. 用接收通知的 QQ 打开机器人会话，发送一句便于识别的文字；群聊请先添加机器人并 @机器人。
3. 在网页中明确选择最近会话，再测试发送。聊天消息只增加候选会话，不会自动改挂收件人。
4. 在 QQ 中核对渠道名称，将收到的 6 位验证码填回网页。完成后显示“已完成验证”。

AppID 与 AppSecret 用于连接机器人；机器人本身不是收件人。普通 QQ 号码不能直接替代 QQ 平台的收件标识。QQ 主动发送能力仍取决于平台权限与额度。

## 邮箱与其他渠道

| 渠道 | 需要准备 |
| --- | --- |
| 邮箱 | 输入发件邮箱自动识别 QQ、Gmail、Outlook；填写授权凭据或连接微软账号。其他邮箱可手动选择服务商，或展开通用 SMTP 参数。收件邮箱单独填码验证。 |
| 企业微信 | 目标群机器人的官方 Webhook |
| 飞书 | 群机器人 Webhook；启用签名时还需签名密钥 |
| 钉钉 | 应用 AppKey、AppSecret、RobotCode 和成员 UserID 或群 OpenConversationID |
| 自定义 HTTP | 接收地址；接收端返回 2xx 和 JSON `{"accepted": true}` |
| 扩展渠道 | 一个 Apprise 通知 URL，实际支持能力取决于对应服务 |

这些渠道也需发送并填回收件验证码。邮箱授权码属于发件账号，无需提供收件邮箱密码。QQ1、QQ2、微信1、微信2等不同收件目标应分别配置、验证，再授权给相应应用。

## 草稿、停用与删除

未完成绑定的渠道为草稿，不能用于分发。退出时可以继续绑定、保留草稿或删除。已验证渠道先停用，再删除；草稿可直接删除。删除清除连接凭据并取消尚未发送的任务，历史投递记录保留，已发送消息不能撤回。


## 邮箱快速配置

1. 在“下游渠道”选择“邮箱”，填写渠道名称和发件邮箱。
2. 常用邮箱自动识别服务商；可以手动选择。识别依据是发件账号，收件地址不会改变发件通道。
3. QQ 填写 SMTP 授权码；Gmail 填写应用专用密码。服务器、端口与加密方式自动填写，默认折叠。
4. 默认勾选“发给自己”。取消勾选后，可填写其他收件邮箱；收件人无需提供密码。
5. 点击“保存并发送验证码”，真实发送一封验证邮件。填回收件码后，渠道才能绑定上游分发。若未找到邮件，也检查垃圾邮件文件夹。

QQ 的授权码需要在 QQ 邮箱设置中开启 SMTP 后生成。Gmail 的应用专用密码需要两步验证，部分组织账号或高级保护账号不可用。此版本 Gmail 使用应用专用密码方式，没有提供 Google 网页登录按钮。

未知后缀或企业自定义域名可手动选择实际服务商；自建服务器使用“其他邮箱 / 通用 SMTP”。旧版手动配置保留，不会因为升级自动更换服务器。新增或变更邮箱、服务器、凭据和收件地址后，按页面提示重新验证。

### 获取 QQ 邮箱 SMTP 授权码

配置页面的“邮箱 SMTP 授权码”旁有“如何获取？”按钮，点击可直接展开步骤，已填写的表单保留。

1. 电脑登录 [QQ 邮箱网页版](https://mail.qq.com/)，点击右上角头像。
2. 进入 **设置 → 账号与安全 → 安全设置**。
3. 找到 POP3 / IMAP / SMTP 服务，点击“开启服务”；已开启则直接继续。
4. 点击“生成授权码”，按页面提示使用手机 QQ 扫码或输入 QQ 密码完成身份验证。
5. 复制生成的 **16 位授权码**，粘贴到文思邮差的“邮箱 SMTP 授权码”输入框。备注可填写“文思邮差”。

SMTP 授权码用于连接发件账号；保存后发送到邮箱的收件验证码统一为 **6 位数字**，用于确认实际收件，两者分别填写。收件验证码单独标注，邮件有效期显示为“十分钟”，避免邮件预览合并数字。QQ 登录密码只在 QQ 官方页面完成身份验证时使用。

步骤与示意图见 [QQ 邮箱官方授权码说明](https://help.mail.qq.com/detail/106/985)。

### 获取 Gmail 应用专用密码

Gmail 输入框旁的“如何获取？”会显示对应说明：登录发件 Google 账号，先开启两步验证，再在 [应用专用密码](https://myaccount.google.com/apppasswords) 中为文思邮差创建密码，将生成的 16 位密码填入页面。部分组织账号、高级保护账号或仅使用安全密钥的账号不提供此选项，详情见 [Google 官方说明](https://support.google.com/accounts/answer/185833?hl=zh-Hans)。

## Outlook / Hotmail 微软授权

微软邮箱通过官方 OAuth2 设备授权和 Microsoft Graph 邮件接口发送，无需填写微软密码，不需要公网回调地址。邮箱授权和收件验证码是两个步骤。

管理员首次使用时，需要登记自己拥有的微软应用：

1. 打开 [Microsoft Entra 应用注册](https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade)，创建应用或选择已有应用。
2. 支持的账号类型需要包含个人 Microsoft 账号；若同时使用企业账号，可选组织和个人账号。
3. 在“身份验证”的高级设置中启用“允许公共客户端流”。设备授权不需要客户端密钥或回调 URL。
4. 在 API 权限中添加 **Microsoft Graph → 委托权限 → Mail.Send、User.Read**。企业目录可能要求管理员同意。
5. 复制“应用程序（客户端）ID”，在文思邮差“邮箱渠道配置 → 微软授权设置”中保存。这里只填写客户端 ID，不能填写客户端密钥。

之后的连接步骤：

1. 输入发件邮箱、收件邮箱并保存，点击“连接微软邮箱”。
2. 点击“打开微软授权页面”，输入页面给出的微软授权码，登录对应的发件账号并同意授权。
3. 文思邮差自动检查授权。账号需与填写的发件主邮箱匹配；不会把其他账号自动挂到该渠道。
4. 授权完成后自动发送收件验证码。填回验证码后显示“已完成验证”。

访问令牌由微软官方 MSAL SDK 自动续期，令牌缓存加密保存。令牌失效、权限撤销或收件配置变化时，会提示重新连接或验证。点击“解除微软授权”会清除本平台保存的令牌并取消该渠道的验证状态；如需撤销微软账号侧已授予的应用同意，可另外在微软账号权限管理中操作。其他渠道不受影响。

正在授权时，关闭窗口会停止本页面检查；重新连接会创建新的授权码。服务重启后未完成的授权需重新开始，已经完成并保存的授权可继续使用。SMTP 及微软邮箱均使用系统网络；受网络限制时请使用 VPN / Clash TUN，不自动切换其他出口。

## 邮件状态与补发

“邮件服务已接受”表示服务器接受发送，并不等于收件人已读。收件码用于确认实际收到了该地址的验证邮件。

SMTP 连接建立前的网络故障、服务器明确临时拒绝会自动重试至投递截止；授权错误提示修复凭据。发送邮件后连接中断、无法确定是否已接受时，保留“结果待核实”，不会盲目重发。微软接口的连接失败或限流也按相同原则处理。
