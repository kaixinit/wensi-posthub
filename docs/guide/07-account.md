# 账号登录与密码管理

## 默认账号与初始密码

默认管理员账号是 **admin**，当前版本为单管理员账号。

使用 Windows 或 Debian / Ubuntu 安装脚本首次安装时，会生成本机独立的初始密码，并显示在安装终端。首次登录后，系统进入“账号设置”，需先修改初始密码。不会使用所有安装通用的固定密码，初始密码不会在 Web 页面或日志中回显。

现有安装升级后仍使用原密码，不会重置账号、渠道或上游密钥。原先只填写密码的登录方式对应 `admin` 账号。首次安装时手动运行 `python -m posthub init`，仍可自行设置密码；需要自动生成时使用：

```text
python -m posthub init --generate-password --data-dir data
```

## 登录后修改密码

1. 点击左侧“账号设置”，或右上角 `admin`。
2. 输入当前密码、新密码，再次输入新密码。
3. 点击“修改密码并重新登录”。新密码需要 12–256 个字符，不能与当前密码相同。
4. 可点击“显示新密码”核对两次输入，或“复制新密码”保存。修改成功后也会弹出新密码保存窗口，默认隐藏，可显示或复制。
5. 点击“已保存，返回登录”，使用 `admin` 与新密码登录。首次改密且尚无上游时，自动进入接入向导。

修改密码会使所有浏览器的旧管理会话失效。上游 API 密钥、渠道凭据、收件验证、消息记录与分发队列保留，已接入的业务应用无需更换 API 地址。

服务器只保存加盐哈希，不提供找回原密码的功能。本次输入的新密码仅临时保留在当前页面；关闭保存窗口或刷新页面后清除，不写入浏览器本地存储。连续输错当前密码会暂时限制修改尝试。不要把密码放入公开截图、上游消息或代码仓库。

## 忘记密码

在安装机器上使用文思邮差的 Python 环境执行：

```text
python -m posthub reset-password --data-dir data
```

按提示输入两次新密码。`data` 必须指向实际数据目录；不要删除 `config.json` 或重新初始化，否则无法解密原有渠道凭据。重置完成后，浏览器需重新登录。

## 升级兼容

0.1.18 将数据库升级至 schema 7，为管理会话增加密码版本校验。旧密码和已有有效会话在升级时保留；之后修改密码时旧会话立即失效，即便异常情况下残留会话记录也不能继续访问。
