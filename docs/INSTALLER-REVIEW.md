# 正式安装包与升级验收

日期：2026-11-12（Asia/Shanghai）。程序版本：0.1.25。

结论：Windows 11 / Python 3.11 的全新安装、同版本重装、0.1.24 与 0.1.19 升级通过。后续同日已补充 Debian 12 / Python 3.11 与 Ubuntu 24.04 / Python 3.12 独立虚拟机实测，全部安装升级场景通过，见 [Linux 专项报告](LINUX-REVIEW.md)。远端 CI 尚未运行。

## 包内容与体积

正式安装 ZIP 为 **8,174,843 字节，约 8.17 MB**，原完整开发归档约 101.38 MB。外层只有 13 个文件，其中一份 wheel 内含完整运行程序、全部渠道适配、字体、图标和 Web 操作手册。

- 移除测试截图、历史验收产物、测试脚本、开发缓存和重复源码副本。
- 运行依赖从已验证的锁定环境和 wheel 元数据提取，共 38 项；新装环境中没有 pytest、aiosmtpd、Playwright 等测试工具，pip check 通过。
- wheel 中全部运行文件逐字节与当前源码比较一致，保留 MIT、字体及图标的许可文件。
- 安装包需要 Python 3.11+，并联网安装运行依赖；不是自带解释器的离线 EXE。

## 实际安装与升级

验收使用含中文和空格的隔离目录，实际调用 PowerShell 安装/升级脚本与安装后的服务进程；没有读取正式账号配置。旧版本使用历史包中的真实 wheel，不仅修改数据库版本号模拟升级。

| 场景 | 结果 |
| --- | --- |
| 全新安装 | 创建 .venv、安装运行依赖、生成初始账号，首次登录改密成功；页面、向导、帮助及两份字体均可加载 |
| 同版本 0.1.25 重装 | 原密码、API 密钥、独立上游配置、渠道验证、加密配置和记录保留 |
| 0.1.24 → 0.1.25 | 升级成功；schema 10 保持，原配置与全部已有数据行保留 |
| 0.1.19 → 0.1.25 | schema 8 → 10 成功；原账号、解密密钥、渠道、代理、消息与历史行保留 |
| 配套备份 | 每次已有数据安装先生成数据库与 config.json 备份；备份数据行、原 schema 和配置摘要与升级前一致 |
| 旧 API 与隔离 | 原 API 密钥仍可使用，同编号重试仍去重；另一上游越权指定渠道被拒绝 |
| 待发/重试续发 | 各场景均恢复 queued 与 retry；成功的分支不重发，取消任务不发送，待配置分发消息继续保留 |
| 二次重启 | 三种升级/重装场景重启后无额外投递，各场景 4 条本机业务测试通知，共 12 条、无重复 |
| 正式启动入口 | 最终 start.ps1 实际启动通过；读取已保存的外部数据目录，前台进程、健康检查和登录正常 |
| 运行中升级保护 | 实际运行服务时升级被拒绝，未创建升级备份或替换程序 |
| 损坏文件保护 | 修改隔离安装包说明文件后升级被拒绝；还原后校验通过，没有额外投递尝试 |

安装实测发现并修正 Windows 隔离 Python 的中文输出编码问题。最终安装路径显式使用 UTF-8；Windows 启动器保持前台等待服务，最终启动入口另行实测通过。

QQ、微信、邮箱保存测试使用虚构凭据并停用外部发送；实际收发由本机 HTTP 接收器执行。上述结果证明安装保留与队列续发，不宣称本轮又完成真实 QQ/微信/邮箱收件。渠道原有实现和之前的真实收件验收仍保留。

## 回归与限制

- **256 项测试通过**：原 251 项回归及 5 项安装保护；0 失败、0 错误。两项第三方弃用警告未导致本机失败。
- PowerShell 启动/安装/升级脚本语法通过；Git Bash 的 bash -n 语法通过，所有 shell 脚本使用 LF。
- 文档链接、帮助同步、GitHub 表单与工作流结构检查通过；CI 已加入 Windows/Ubuntu 安装验收，但没有远端运行记录。
- 本节为 Windows 实机结果；后续 Linux 虚拟机验收已覆盖 Debian 12 / Python 3.11 和 Ubuntu 24.04 / Python 3.12。Docker、Python 3.13 与物理 Linux 机器仍未验收。
- 升级需先停止旧服务。pip 安装中断后不保证旧运行环境仍完整；备份会保留，可排错重试或用旧程序与升级前配套数据回退。数据回退还需核对备份后已投递消息，避免重复。

操作步骤见 [安装与升级说明](INSTALLER.md)。维护工作区 `artifacts/installer025/` 保留脱敏结果、启动检查和 JUnit；正式安装包不包含这些资料。真实生产服务、Clash 设置与个人渠道凭据未被安装测试修改。
