# 文思邮差 v0.1.25 · 第一版

文思邮差是一个基于 Python 的消息中转与分发平台：上游只接入一次 API，由平台按各上游独立配置的下游渠道分发。

> **目前已适配：QQ 机器人、微信 ClawBot、QQ 邮箱。更多渠道接入正在适配与验证中。**

这是首个 GitHub 版本，沿用程序版本 0.1.25，处于早期试用阶段。

## 已适配渠道

- **QQ 机器人**：AppID / AppSecret 配置、会话识别、6 位收件验证码；已完成真实消息收件验证。
- **微信 ClawBot**：本人微信扫码绑定、会话同步、6 位收件验证码；已完成真实收件及新会话恢复验证。
- **QQ 邮箱**：自动配置 SMTP 服务器，填写邮箱账号和 SMTP 授权码；已完成验证邮件与通知收件验证。

Gmail、Outlook、企业微信、钉钉、飞书等更多接入正在适配与验证中。已有适配器或界面入口不代表对应真实账号已验收，请以 README 的渠道矩阵为准。

## 第一版功能

- 每个上游拥有独立接口、密钥与下游授权，配置互不影响。
- 同一条消息可分发到多个渠道，支持预约发送和投递截止时间。
- 消息持久化保存；安全连接失败、限流等情况自动重试，已成功渠道不自动重发。
- 同一业务事件重试沿用原业务编号，避免重复创建消息。
- Web 管理界面提供首次接入向导、投递记录、故障指引、网络通信配置、账号改密及内置操作手册。

## 下载与安装

下载 Release 附件 **`文思邮差-0.1.25.zip`**，Windows 11、Debian、Ubuntu 使用同一安装包。包大小约 8.17 MB，需要 **Python 3.11+**，首次安装需要联网下载运行依赖。

- Windows：解压后运行 `install.ps1`，然后运行 `start.ps1`。
- Debian / Ubuntu：准备 Python 与 `python3-venv` 后，运行 `bash install.sh`，然后运行 `bash start.sh`。
- 默认打开 `http://127.0.0.1:8787`；账号 `admin`，使用安装时生成的独立初始密码，首次登录后修改。

这是 Python Web 服务安装包，不是内置 Python 的离线 EXE。完整命令见 [安装与升级](../INSTALLER.md)。

## 使用边界

- QQ、微信的发送权限、额度和会话有效性受渠道平台限制；QQ 邮箱使用 SMTP 授权码。
- HTTP 202 表示平台已保存；“渠道已接受”表示渠道返回成功，不等于收件人已读。
- 未知回执需先核实收件；第三方接口限制使平台不能承诺端到端必达或绝对只发一次。
- 当前为单机、单管理员、单服务进程，采用 SQLite；尚不支持多租户、多实例。
- Docker、ARM、systemd 开机自启和全部扩展渠道的真实账号验收范围见 [测试说明](../TESTING.md)。
